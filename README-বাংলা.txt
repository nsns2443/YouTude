YouTude APK বানানোর ধাপ (কোড জানা লাগবে না)

১. github.com এ ঢুকুন (অ্যাকাউন্ট না থাকলে বিনা পয়সায় খুলুন)।
২. ওপরে ডানে "+" চেপে "New repository" বেছে নিন। নাম দিন: youtude। "Private" রাখতে পারেন। "Create repository" চাপুন।
৩. নতুন পাতায় "uploading an existing file" লেখায় চাপুন।
৪. এই ZIP আনজিপ (Extract) করে ভেতরের সব ফাইল ও ফোল্ডার (app, .github, build.gradle, settings.gradle, gradle.properties, icon-1024.png) টেনে এনে ওই পাতায় ছেড়ে দিন। নিচে "Commit changes" চাপুন।
   - ".github" ফোল্ডার না উঠলে: "Add file" → "Create new file" চাপুন। নামের ঘরে লিখুন:  .github/workflows/build.yml
     তারপর build.yml ফাইলের লেখা কপি করে বড় ঘরে পেস্ট করুন, "Commit changes" চাপুন।
   - আগে থেকে repository থাকলে একই ফাইলগুলো আবার তুলে দিলে পুরনোগুলো বদলে যাবে।
৫. ওপরের "Actions" ট্যাবে চাপুন। ৩-৫ মিনিট অপেক্ষা করুন, সবুজ টিক এলে হলো।
   ("Workflows aren't being run" লিখলে সবুজ বোতাম চেপে চালু করে নিন।)
৬. সবুজ টিক দেওয়া কাজটায় চাপুন। একদম নিচে "Artifacts" এর নিচে "YouTude-APK" ZIP নামান। আনজিপ করলে app-debug.apk পাবেন।
৭. APK বাচ্চাদের ফোনে ইনস্টল করুন ("Install unknown apps" অনুমতি চাইলে দিন)। আগের অ্যাপ থাকলে ওপর দিয়েই আপডেট হবে।

স্ক্রিন পিনিং (এখন হাতে হাতে, PIN দিয়ে):
- অ্যাপ খুললে নিজে থেকে পিন হয় না, কোনো পপআপও আসে না।
- বাচ্চাকে ফোন দেওয়ার আগে: ⚙ চাপুন → Admin PIN দিন → বাবা-মায়ের প্যানেলে "📌 স্ক্রিন পিন করো" চাপুন → আবার Admin PIN দিন → ফোন একবার জিজ্ঞেস করবে, "OK" চাপুন।
- পিন খুলতে: লোগোতে ৩ সেকেন্ডে ৩ বার চাপুন, Admin PIN দিন (অ্যাপ বন্ধ হবে)। অথবা ⚙ প্যানেলে "📌 স্ক্রিন পিন খোলো" বা "📱 অ্যাপ থেকে বের হও" চাপুন।
- (ফোনের Settings → Security-তে "App pinning" একবার চালু থাকতে হবে।)

বড় পর্দা বোতাম চাপলে ভিডিও আড়াআড়ি (landscape) হয়ে যাবে।
ব্লগের ঠিকানা বদলাতে হলে: app/src/main/java/com/azhar/youtude/MainActivity.java ফাইলে HOME_URL লাইনটা বদলান।

নতুন যা আছে এই APK-তে:
- স্ক্রিন বন্ধ করলে বা অন্য অ্যাপে গেলেও ভিডিওর শব্দ চলতে থাকবে (ওপরের বার টানলে "YouTude — ভিডিও চলছে" দেখাবে)।
- YouTube অ্যাপে কোনো ভিডিও বা প্লেলিস্টে "Share" চাপলে তালিকায় YouTude আসবে। চাপলে অ্যাপ খুলে জিজ্ঞেস করবে "এই ভিডিও যোগ করবেন?" (Master Admin দিয়ে লগইন থাকতে হবে)।
- Parents/Admin লগইনে ওপরে 📌 আইকন: চাপলে স্ক্রিন পিন চালু, আবার চাপলে বন্ধ।
